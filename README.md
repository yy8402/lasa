# LASA

LASA is a layered agent service implemented in Python with Codex App Server. It provides workspace-bound sessions, asynchronous tasks, approved outcome contracts, bounded delegation, source verification, and diagnostics.

All implementation, tests, design documents, deployment tools, and reviewed verification evidence are in [`v0`](v0/README.md).

- [Run and configure the service](v0/RUNNING.md)
- [Architecture and protocol](v0/design/README.md)
- [Application and MCP integration design](v0/design/connectors.md)
- [Managed rollout and live dependent-workflow verification](v0/deployment/DEPLOYMENT.md)
- [Historical connector integration results and diagnostic commands](v0/deployment/CONNECTORS.md)
- [Implementation verification](v0/VERIFICATION.md)

Local deployments, credentials, generated runtime state, virtual environments, and historical research folders are excluded from version control.
