# LASA

LASA is a layered agent service implemented in Python with Codex App Server. It provides workspace-bound sessions, asynchronous tasks, approved outcome contracts, bounded delegation, source verification, and diagnostics.

The [service source tree](v0/README.md) contains the implementation, tests, protocol, and deployment instructions.
