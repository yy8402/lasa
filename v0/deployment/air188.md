# air188 deployment

Air188 runs the primary and review `lasa-supervisor:1.0.0` containers at deployment revision `docker-1.0.0-typed-982347ae1b54`. Both advertise `lasa/1.0.0`. The system `lasa-layer2-https.service` proxies both HTTPS endpoints using `/etc/lasa/layer2.Caddyfile` and its installed backend CA. Use `yang@192.168.0.188` for administrative SSH.

| Role | HTTPS API | Container | Loopback port | Authentication |
| --- | --- | --- | --- | --- |
| Primary | `https://192.168.0.188/lasa/v1` | `lasa-primary` | 8878 | JWT |
| Review | `https://192.168.0.188/review/lasa/v1` | `lasa-review` | 8879 | Static token with workload identity pin |

## Directory layout

- `~/.config/lasa/{primary,review}/` holds each role's `1.0.0` `config.json` and separate `authorization.json`.
- `~/.config/lasa/secrets/{primary,review}/` supplies model and TLS files. Primary also reads its issuer JWKS here.
- `~/.config/lasa/registries/review/static-tokens.json` holds the static-token digests, subjects, and expirations. Update the registry from an administrator environment using the token issuance command. [Static tokens](../RUNNING.md#static-tokens)
- `~/.local/state/lasa/{primary,review}/` holds the derived `private/` and `workspaces/` directories. Each supervisor has one writable state mount.
- `~/.local/share/lasa/connectors/` provides the filesystem MCP executable and `~/.local/share/lasa/documents/` contains its approved source files. Primary mounts both read-only.
- `~/.local/state/lasa/archives/pre-1.0.0-20261123/` contains the verified `primary/state.tar.gz` and `review/state.tar.gz` archives, their checksums, and archived predecessor deployment files.
- `~/.local/state/lasa/archives/pre-unified-1.0.0-20261123/` holds the earlier verification stores and their manifests and policies. Both active stores use SQLite schema revision `1`.
- `~/.local/state/lasa/releases/1.0.0/typed-workflows/<role>/predecessor/` holds the prior config and policy for the stopped `lasa-primary-pre-typed` and `lasa-review-pre-typed` containers.
