The system `lasa-layer2-https.service` proxy serves both HTTPS endpoints using `/etc/lasa/layer2.Caddyfile` and the installed backend CA at `/etc/lasa/docker-1.2.0-ca.pem`.

| Backend | HTTPS API | Container | Loopback port | Authentication |
|---|---|---|---|---|

Use `yang@192.168.0.188` for administrative SSH. The Mac parent delegates to each backend over authenticated HTTPS using its separately configured peer credential.

Each 1.5.2 manifest references its separate authorization policy and private files under `conf/`. Primary's JWT JWKS is under `primary/conf/`. Review's token registry and its lock remain under `review/deployment-1.5.0/`. The versioned policy and registry paths serve both 1.5.2 and 1.5.1. Each role keeps its task store in `private/` and its session files in `workspaces/`.
